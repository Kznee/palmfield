All runtime dependencies and the hand landmark model are served locally.
No external fonts, trackers, API keys, analytics, or uploads are used.

assets/neon-drive.mp3 is an original 60-second, 128 BPM stereo electronic
demonstration composition created for this project. It contains no external
recordings or samples. The project audio was rendered at 44.1 kHz and encoded
as 256 kbps MP3.
